# V1_SCOPE.md

## 第一版定位

第一版只面向中介使用，目标是先把中介找房、管理房源、查看地图和个人入口跑通。暂不扩展房东端、租客端、房源群运营、积分体系、充值体系或微信支付入口。

## 导航范围

底部导航固定为四个入口：

- 找房
- 房源
- 地图
- 我的

房源群、积分、充值、微信支付等入口在第一版必须隐藏，不作为可见功能入口。

## 地图范围

地图只展示真实且已确认的小区坐标。任何随机坐标、散列坐标、区域估算坐标、默认中心坐标都不得进入地图数据或地图展示链路。

如果小区坐标未确认，应保持不可上图状态，而不是使用临时坐标占位。

## 房态范围

房态提醒与失效规则固定如下：

- 第 3 天提醒
- 第 5 天提醒
- 第 7 天失效

## 报备范围

报备保持简单，只保留第一版中介流转所需的最小信息与操作，不引入复杂审批、复杂角色、复杂状态机或额外协同流程。

## 分佣范围

上传房源的中介分佣为房东实际支付佣金的 20%。计算口径以房东实际支付佣金为准，不以租金、挂牌价或预估佣金为准。

## 明确不做

第一版不开发以下内容：

- 房源群
- 积分
- 充值
- 微信支付入口
- 面向房东或租客的独立流程
- 使用未确认坐标的地图展示
- 复杂报备审批流

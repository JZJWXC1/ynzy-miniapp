# 小程序发版前 5 分钟自查清单

> 更新日期：2026-07-14 · 适用：游客合作房源公开预览、敏感信息保护与匿名视频传播。
> 背景：自动测试不能替代微信开发者工具和真机验证；本清单专门检查“公开内容可用、敏感内容不泄露、旧功能不回退”。
> 发版前请在微信开发者工具（连真实后端，`utils/deploy-config` 默认已指向生产）按此清单过一遍。
> ⚠️ 注意：后端已切换为密码登录制，**旧版前端的登录已不可用**——本次发版是恢复登录能力的前提。

## A. 登录 / 注册（pages/auth）
- [ ] 登录页有「手机号 + 登录密码」两个输入框，tab 为「手机号登录 / 账号注册」
- [ ] 错误密码登录 → 弹「登录失败」且提示语不泄露账号是否存在（应为「手机号或密码不正确」）
- [ ] 注册 tab：姓名/手机号/密码/确认密码四项；密码 <8 位或两次不一致时被前端拦截
- [ ] 提交新注册 → 弹「注册申请已提交」，文案含「已收到您的注册信息，期待和您的合作…」（不是报错样式）
- [ ] 已开通手机号再注册 → 弹「该手机号已开通」，点「去登录」切回登录 tab

## B. 修改密码（pages/change-password，新页面）
- [ ] 「我的」页登录后出现「修改密码」按钮，能打开新页面且布局正常（三个输入框 + 保存按钮）
- [ ] 原密码错 → 弹「修改失败：原密码不正确」；改成功 → toast「密码已修改」并返回
- [ ] 改完退出重登：旧密码被拒、新密码能登

## C. 「我的」页（pages/profile）
- [ ] 内部工作台每项只有「功能名称 + 右上角数值」，无说明文字，卡片不显松散/不塌
- [ ] 原「防跳单与分佣提醒」板块标题已是「今日工作台」，右侧「全部」按钮仍可点
- [ ] 「切换账号 / 修改密码 / 退出登录」三个按钮排版正常

## D. 房源卡片封面（首页 / 房源列表 / 我的房源 / 详情）
- [ ] 有视频的房源卡片显示视频首帧封面图 + 「视频」角标（生产 79 套有视频房源应基本都有图）
- [ ] 无视频房源显示原占位图，**没有裂图图标**
- [ ] 列表快速滚动不明显卡顿（封面已 lazy-load）
- [ ] 房源详情页视频未播放时显示首帧 poster，点播放正常
- [ ] 页面长时间停留或切换网络后，视频/封面首次失败会自动刷新一次并恢复；不会循环请求或要求游客登录
- [ ] 游客“保存视频”在弱网下可继续等待，地址失效时只刷新并重试一次；取消分享/拒绝相册权限不会二次发送或伪记留痕

## E. 我的房源（pages/my-listings）
- [ ] 卡片为新样式（左封面 + 右信息），含房东电话直显行与房态核验行
- [ ] 「编辑」「电话确认」按钮都在且可点：电话确认 = 拉起拨号 → 挂断后弹「已出租/未出租/不租了」三选一
- [ ] 新筛选面板可用：整租/合租、小区名（有联想）、租金区间；筛「两室」能筛出「二室」房源
- [ ] 筛选后统计数字（在租/被查看/待电话确认）不变（统计基于全量，属预期）

## F. 回归抽查（老功能没被带坏）
- [ ] 游客（未登录）能浏览公司、业主、二房东三类有效房源卡片和详情视频；三类来源筛选不串类
- [ ] 游客合作房源只显示城市、区域、板块、小区等公开信息；楼栋、单元、房号、完整地址、电话、看房方式、钥匙、密码和敏感备注均未泄露
- [ ] 游客可播放、转发和保存合作房源视频；收藏、拨号、带看和查看完整信息仍提示登录
- [ ] 公司房源继续完整展示服务器配置的统一号码和原有公开字段，不出现公司“联系房东”按钮
- [ ] 抽查“4 位房号 + 服务器统一号码 + 原始私号/座机”相邻的公司存量文案：统一号码完整，原始私号和座机均不残留
- [ ] 抽查含地铁线、步行分钟、公交线路、户型、面积、年份、版本/日期/比例和“手机信号好”“密码保护 WiFi”等正常文案的合作房源：业务内容仍显示；用标点、字母、汉字、emoji、不可见字符、中文十百千写法或希腊/西里尔同形字拆开的电话/门牌均不显示且不能被搜索命中
- [ ] 抽查公开标题/标签/备注中的裸 `t.me`、`wa.me`、邮箱和社交别名：页面与找房助手均不显示，也不能用这些私联内容反向搜到房源
- [ ] 首页公司房源表保留房号和看房密码，但任何简介/联系电话列不出现房源原始手机/座机、邮箱、Telegram/WhatsApp/微信账号、私聊域名或外链，也不出现飞书表链接或内部 token/range
- [ ] 从小区联想选择一个与其他小区存在同名前缀的官方小区：列表、地图、收藏和找房助手只返回精确小区；直接输入未收录自由文字仍可模糊查找
- [ ] 地图选定小区后首次点“列表找房”：房源类型、租赁方式和小区筛选全部保留，不因首次跳转、登录或换号丢失合法筛选
- [ ] 同一手机并发打开/保存多个房源视频时，单客户端超出上限会明确失败但其他设备仍可访问；取消、断网、上游失败后稍后重试能恢复，不出现并发名额永久占用
- [ ] 已撤销或过期的本地登录态不会阻断公开列表/详情/视频：页面静默回到游客公开内容，不跳登录；收藏、拨号、带看、敏感查看仍要求重新登录
- [ ] 找房助手（首页输入需求）正常返回推荐
- [ ] 地图页正常加载点位
- [ ] 上传房源全流程能走通（选视频 → 提交）

全部勾完再点「上传」→ 提交审核发版。任何一项不过：截图 + 页面路径发给 Claude/Codex 修。

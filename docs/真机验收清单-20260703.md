# 真机验收清单（2026-07-03）

## 1. 库外小区上传审核

- 操作：用真机上传一个不在小区库中的小区名，完成房源视频和必填信息提交。
- 预期结果：我的房源中该房源显示“待审核”；首页、房源列表、地图均不出现该房源；管理后台审核通过后，前台列表可见。
- 截图点位：我的房源状态标签、首页无该房源、房源列表搜索无该小区、地图无该小区点位、后台审核前后状态。
- 不通过排查：检查小区名是否实际已在服务端小区库；检查房源 `reviewStatus`、`requiresManualReview`、`communityMatchStatus`；确认前端没有缓存旧列表。

## 2. 历史入口下线

- 操作：真机打开第一版小程序，检查群、积分、充值、换群相关入口；同时用接口验证历史路由。
- 预期结果：小程序不展示群、积分、充值、换群入口；`/mini/points/recharge` 与 `/mini/groups` 返回 404；`/mini/listings` 正常返回 200。
- 截图点位：底部导航仅有找房、房源、地图、我的；我的页无积分充值；房源页无房源群入口。
- 不通过排查：检查生产环境是否显式设置了 `V1_DISABLE_LEGACY_ROUTES=0`；确认部署服务已重启到最新包。

## 3. 地图找房

- 操作：进入地图页，切换租金、户型、租法、房源来源等筛选条件，并拖动地图视野。
- 预期结果：地图只展示已确认坐标的小区；无坐标或待审核房源不进入地图；筛选切换后视野不回跳，套数跟随最后一次筛选结果。
- 截图点位：地图点位、小区聚合卡片、筛选条件、套数统计。
- 不通过排查：检查房源是否有 `coordinateVerified=true` 和真实 `mapLatitude/mapLongitude`；检查是否存在默认中心点、随机坐标或客户端手填坐标被采信。

## 4. 视频上传

- 操作：上传一个正常视频，再尝试上传一个超过限制的大视频。
- 预期结果：正常视频显示实时百分比并上传成功；超大视频在上传前被预检拦截，给出明确失败提示，不进入房源提交。
- 截图点位：上传进度百分比、上传成功状态、超大视频拦截提示。
- 不通过排查：检查 OSS 上传策略接口、视频大小预检逻辑、手机网络权限和上传域名白名单。

## 5. 首页节流

- 操作：在首页与其他 tab 间来回切换，连续操作 60 秒。
- 预期结果：60 秒内不重复刷新飞书快照；首页内容不闪烁、不重复插入、不出现明显加载抖动。
- 截图点位：首页列表稳定状态、切 tab 前后列表内容、无重复加载提示。
- 不通过排查：检查首页缓存时间、飞书快照刷新触发条件、前端 tab 生命周期是否重复触发请求。

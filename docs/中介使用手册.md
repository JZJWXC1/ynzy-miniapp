>
> 适用对象：使用「寓你住一起」小程序找房、带客、成交的房产中介。

## 快速上手：四步开始用

第一次用寓你，只需要走这四步：

1. **注册申请**：打开小程序 → 底部「我的」→「切换账号」进登录页 → 切到「账号注册」，填姓名、手机号，自己设一个登录密码（至少 8 位），点「提交注册申请」。
2. **等管理员开通**：提交后会提示"已收到您的注册信息，期待和您的合作，请联系寓你住一起管理员开通账号权限"。把姓名和手机号告诉你的管理员，请他在后台审核开通。
3. **登录**：管理员开通后，回到登录页「手机号登录」，输入手机号 + 你注册时设的密码，点「登录」。
4. **改密（可选）**：登录后在「我的」页可以随时点「修改密码」换成自己好记的密码。

## 1. 寓你是什么，你能用它做什么

寓你是一个**面向内部中介团队**的找房协作工具。它不是给租客用的公开租房 App，而是帮你（中介）把手上的租客需求快速对上真实、可租、有视频的房源，并记录敏感信息查看、实际拨号、带看审核和房态操作，避免跳单、保护上传人的权益。

一条完整的业务闭环是这样的：

> 录入租客需求 → 找房助手/地图推荐房源 → 看房源视频、校验房态 → 二次确认查看房东电话和地址（留痕）→ 打开系统拨号页（电话查看留痕）→ 现场带看并上传水印照片。

> 客户报备和成交签单当前暂停，页面没有新增入口；历史记录由后台只读保留。

## 2. 登录与注册

### 2.1 怎么进入登录页

- 第一次打开小程序，或在需要登录的操作（查看房东电话、上传房源、查看足迹等）时，系统会弹窗提示你去登录，点**"去登录"**即可进入登录页。
- 你也可以在底部**"我的"**页，点用户卡右上角的**"切换账号"**，或工作台里的**"登录与账号信息"**进入。

### 2.2 登录步骤（已开通账号）

1. 进入**"登录注册"**页，默认停在**"手机号登录"**，页面提示"已开通账号请输入手机号和登录密码"。
2. 填写你的 11 位**手机号**。
3. 填写你的**登录密码**（注册时自己设的，或管理员帮你设置的初始密码）。
4. 点**"登录"**。成功后提示**"登录成功"**，自动返回上一页或进入"我的"页。

**登录失败常见提示：**

| 提示 | 什么意思 / 怎么办 |
| --- | --- |
| "该手机号未开通内部中介账号，请联系管理员开通" | 你还没有账号。切到"账号注册"提交注册申请，或直接把姓名+手机号报给管理员开通。 |
| "账号尚未设置登录密码，请联系管理员开通或重置密码" | 账号是老账号或后台新建的，还没有密码。联系管理员在后台帮你"设置密码"，拿到初始密码后再登录。 |
| "手机号或密码不正确" | 密码输错了。想不起来就联系管理员在后台重置。 |

> 提示：短时间内反复输错会被暂时限制登录（防止有人试你的密码），稍等一会再试。
> 登录状态大约保持一周，过期后系统会自动退回登录页，重新登录即可，不会丢失你的房源和记录。

### 2.3 注册步骤（新账号）

**寓你是内部协作工具，新账号采取"申请—管理员审核—开通"的方式**，任何人都可以提交申请，但要等管理员审核通过后才能登录。

1. 在登录页点**"账号注册"**切换到注册模式。
2. 填写四项：
   - **真实姓名**：必填，管理员按这个核实你的身份。
   - **手机号**：11 位手机号，以后就用它登录。
   - **登录密码**：自己设置，**至少 8 位、不能有空格**。
   - **确认密码**：再输一遍，两次要一致。
3. 点**"提交注册申请"**。
4. 提交成功会弹窗**"注册申请已提交"**，内容是：**"已收到您的注册信息，期待和您的合作，请联系寓你住一起管理员开通账号权限"**。

**接下来怎么办：** 主动联系你们公司的管理员，报上姓名和手机号，请他在后台"注册审核"里通过你的申请。**审核通过后，你注册时设的密码直接生效**，回到"手机号登录"输入手机号+密码即可登录，不用再注册一次。

**如果你的手机号已经开通过账号**，再提交注册会弹窗**"该手机号已开通"**：
- 提示"该手机号已开通账号，请直接用手机号和密码登录"→ 点"去登录"直接登录；
- 提示"该手机号已开通但尚未设置登录密码，请联系管理员重置密码后登录"→ 找管理员在后台帮你设初始密码。

## 3. 修改密码

登录之后可以随时自助改密码：

1. 底部**"我的"**页 → 用户卡上点**"修改密码"**（登录后才显示这个按钮）。
2. 进入**"修改密码"**页，填三项：
   - **原密码**：当前登录密码。
   - **新密码**：**至少 8 位、不能有空格**，且不能和原密码相同。
   - **确认新密码**：再输一遍。
3. 点**"保存新密码"**，成功提示**"密码已修改"**。

> 页面下方也写了：修改成功后，下次登录请使用新密码。**忘记原密码改不了？联系管理员在后台重置一个初始密码给你，登录后再自己改掉。**

## 5. 找房助手：说一句话就能配房

**入口：** 底部**"找房"**页顶部的"寓你找房助手"卡片，或直接点进"找房助手"对话页。

找房助手是一个**对话式**的小助手，界面像聊天。顶部标题是**"找房助手"**，副标题"一句话匹配真实可租房源"。

### 5.1 用文字找房

1. 在最下方输入框里，用一句话描述租客需求，例如"滨江四千以内两室，要有燃气"。
2. 点右侧**"找房"**按钮（匹配时会变成"匹配中"）或键盘回车发送。
3. 助手会回复：
   - **条件够了** → 直接给你推荐卡片，并按预算、位置和偏好排序。
   - **条件不够** → 只追问一个关键问题，比如"预算大概多少？"你把缺的信息补一句发过去即可。

### 5.2 用语音找房

1. 点输入框旁边的**麦克风**按钮开始说话，说完停止后会自动发送。
2. 若提示"当前环境暂不支持语音输入""没有识别到内容""语音识别失败"，改用文字输入即可。

### 5.3 增量修改需求（"预算改成3500，其它不变"）

**不用重新描述，只要再发一句改动**：

- 例如上一轮说的是"滨江两室四千以内"，直接再发一句**"预算改成3500，其它不变"**，助手只改预算、其它条件保留，然后重新推荐。
- 如果某一轮出现了可编辑的"确认找房字段"卡片，也可以直接在卡片里改对应字段，再点**"确认并匹配"**。

### 5.4 读懂推荐卡片

推荐结果会分成**"符合要求"**和**"接近要求"**两组。每张卡片上有：标题（小区 · 户型）、右上角相关度百分比、月租/小区/户型一行事实、推荐理由、距离与差异、特点标签，底部有**"看详情"**和**"地图查看"**两个按钮。

卡片下面还有**"有用" / "不准"**两个反馈按钮，点一下可以把这次推荐的好坏反馈给后台，帮助持续优化助手。

### 5.5 常见情况

- **推荐为空**：按提示放宽预算、区域或户型再试。
- **网络失败**：点"重试匹配"即可。

## 6. 房源列表与筛选

**入口：** 底部**"房源"**页。顶部标题会随分类变化，例如"全部房源"。

### 6.1 顶部分类标签（按房源来源分）

页面最上方一排分类标签：**全部 / 公司房源 / 业主房源 / 二房东房源**。点一下切换。

> 注意：**整租/合租不在顶部分类里**，它在下方筛选面板的"租赁方式"里选。

### 6.2 筛选面板

分类标签下方是统一的筛选面板，从上到下：

- **区域**：不限 + 可选区域（选项随房源库变化，以页面为准）。
- **板块**：选了区域后出现对应板块。
- **小区**：输入框，边输入边联想匹配小区，也可以直接从下拉里选。
- **户型**：不限 / 一室 / 两室 / 三室等。
- **租赁方式**：不限 / 整租 / 合租。
- **租金区间**：填"最低租金""最高租金"。
- 填好后点**"筛选"**，或点**"重置"**清空。

### 6.3 房源卡片怎么看

每张卡片是**封面图 + 信息**的样式：

- **左侧封面图**：有视频的房源自动用**视频第一帧画面**做封面，右上角有"视频"角标；封面暂时取不到时显示占位窗格，不影响点进去看视频。
- 整租房源标题前有"整"字徽标。
- 标题、位置（小区 · 房号）、户型 · 来源 · 房态。
- 特点标签（近地铁、燃气、电梯等）和房态维护标签（如"今日已维护""3天前维护"）。
- 底部是月租和佣金/来源标签。

汇总栏会显示"某分类 · N 套"和固定说明"实名查看留痕 · 视频房源"。

- **没有结果**：显示"可以调整区域、户型或租金条件后重新筛选"。
- 点任意卡片进入**房源详情页**（看视频、查房东电话地址、拨号和记录带看都在详情页做）。

## 7. 地图找房

**入口：** 底部**"地图"**页，标题"地图找房"。头部写着"可上图小区位置""已确认、近似定位和板块中心兜底会分级标注"。

> 说明：地图上**只显示小区级位置，不显示具体楼栋、单元、房号和房东电话**。坐标按可靠程度分级标注（管理员确认过的最准）。地图是**按你当前看到的地图范围搜房**，不是"按半径搜"。

### 7.1 筛选条件（比列表页多了"房源类型"快捷筛选）

- **租金快捷**：全部 / 各租金档位，也可以自己填"最低租金""最高租金"后点"应用"。
- **户型**：全部 / 一室 / 两室 / 三室。
- **租赁方式**：全部 / 整租 / 合租。
- **房源类型**：全部 / 公司房源 / 业主房源 / 二房东房源。

### 7.2 操作

1. 拖动地图到你想找的片区。
2. 地图上会出现**"搜索当前区域"**按钮，点它按当前范围重新搜房。
3. 每个小区气泡上显示小区名、套数和租金区间。
4. 点小区气泡弹出该小区的房源清单，点**"看详情"**进入房源详情页。
5. 想切回列表方式看，点**"列表找房"**，会把当前筛选条件带到"房源"页。

## 8. 房源详情：查看房东电话和地址（敏感信息留痕）★重点

房东电话和详细地址属于**敏感信息**，默认是隐藏的，需要你主动查看，而且**每天有额度、查看会留痕**。这是防跳单、保护上传人的核心机制，请务必看懂本节。

### 8.1 在哪里查看

进入任意**房源详情页**，找到**"地址和房东联系方式"**卡片：

- 卡片说明写着"查看即留痕，同步给上传人和管理员。"
- 未查看时，"详细地址"和"房东电话"两行都显示**"完成确认后可查看"**。

### 8.2 查看步骤

1. 点卡片下方的按钮**"查看地址和电话"**。
2. 如果还没登录，会提示"登录后查看地址电话"，先去登录。
3. 页面弹出**二次确认**，说明查看会留下服务端足迹并同步给房源上传人和管理员。
4. 点**"确认查看"**。不需要绑定需求单，也不需要填写用途。
5. 成功后提示**"已记录查看足迹"**，地址和房东电话就显示出来了。

足迹只保存账号、房源、动作、服务端时间和幂等标识，不保存电话、地址、需求内容或查看用途。

### 8.3 每日额度规则（务必记住）

系统按房源类型分两种额度，**每天 0 点重置**：

| 房源类型 | 每天可查看数量 |
| --- | --- |
| **业主房源** | **3 套 / 天** |
| **普通房源**（二房东等） | **15 套 / 天** |

额度的几个要点：

- **同一套房源，当天重复查看不再扣额度**。
- 同一套房源当天重复确认只保留一条查看足迹；网络丢响应后重试也不会重复计数。
- **查看自己上传的房源，不占用额度**（自己房源的房东电话直接展示）。
- **带看审核通过，当天普通房源额度 +1**（见[第 11 节](#11-记录带看拍水印现场照换额度)）。

### 8.4 额度用完了怎么办

当天额度用尽后再查看，会弹窗**"今日额度已用完"**。处理办法：

- 优先安排真实带看并上传水印照，审核通过可当天多拿普通房源额度；
- 或联系管理员，由管理员帮忙联系房东；
- 或第二天额度重置后再看。

### 8.5 常见提示

- **提示"需要实名认证 / 去实名"**：按提示完成实名后再查看。
- 当前版本不会再要求绑定需求单或填写查看用途；如果旧页面仍出现这类提示，请退出该页后重新进入最新版。
- **提示“操作过于频繁”**：系统正在保护审计记录，请等待约一分钟后再试；已成功的同一次拨号补记不会因重试丢失。

## 9. 上传房源

**入口：** "我的"页工作台的**"上传房源"**，或"我的房源"页顶部的**"上传"**按钮；在"我的房源"里点某套房源的**"编辑"**是编辑模式。

### 9.1 房源归属

- **普通中介账号**：只能上传**"合作房源"**（二房东房源 / 业主房源）。
  - **二房东房源**：合作房源，按房态规则维护。
  - **业主房源**：合作房源，**提交后需管理员审核通过才上架**。
- **公司房源只有管理员能上传**，普通账号选它会被拦截。

### 9.2 需要填的内容

1. **位置**：城市、区域、小区名称（输入时自动匹配小区库）、几栋 / 几单元 / 房间号。
   - 若提示"未匹配小区库，提交后需管理员审核通过才上架"，说明这个小区不在库里，提交后要等审核。
2. **户型**：租法（整租 / 合租）、几室、几厅、几卫。
3. **房源特点（必选）**：至少选一个标签，包含 `Loft`、`落地窗` 等；确实没有明显特点就选"无"。
4. **房东手机号**：所有房源类型和所有看房方式都必须填写合法 11 位手机号，不能用微信号或占位文字代替。
5. **租金与房东佣金**：月租必填；房东佣金占月租比例只允许 0–100 的整数，默认 50。
6. **房源备注（可选）**：最多 200 字，不得填写手机号、微信号、二维码或联系方式链接。
7. **视频**：**合作房源必须上传视频，只能选视频、不能用图片冒充**。视频时长上限 60 秒、大小上限 300MB。

> 上传的视频还会自动生成房源卡片封面（取视频第一帧），拍视频时开头一两秒尽量对准房间主体，封面会更好看。

### 9.3 提交

- 点底部按钮提交（二房东房源"提交合作房源"、业主房源"提交审核"、编辑时"保存房源修改"）。
- 提交前会弹确认窗，核对地址、户型和归属提示。
- 缺必填项会弹"还差一点"并列出缺哪几项；视频太大会提示压缩后再传；成功会提示"上传成功"。

### 9.4 关于审核与重复

- **业主房源、或小区没匹配上库的房源，必须等管理员审核通过后才会上架**，审核前其他中介看不到。
- 同一小区、楼栋、单元、房号、房东手机号已有一套有效房源时，系统会拦截，提示不要重复上传。

## 10. 我的房源维护（电话确认三选项）

**入口：** "我的"页 → **"我的房源"**。

### 10.1 页面怎么看

- 顶部有**筛选面板**（和房源列表页一样）：区域、板块、小区、户型、**整租/合租**、租金区间，方便你在自己的房源里快速定位某一套。
- 房源卡片是新的**封面图样式**：视频首帧封面 + "视频"角标，整租有"整"字徽标，自己上传的房源**直接显示房东电话**（不用留痕查看）。
- 卡片下方一行显示查看次数和核验状态（如"今日已维护""3天前维护""7天未维护"）。
- 每张卡片右下角有两个按钮：**"编辑"**和**"电话确认"**。

### 10.2 房态维护节奏（3 / 5 / 7 天规则）★

为保证房源真实可租，系统对每套房源有固定的核验节奏：

- **第 3 天**未更新：提醒你打电话联系房东核验房态。
- **第 5 天**未更新：再次提醒。
- **第 7 天**仍未更新：**自动失效下架**，前台不再展示，进入后台资产池（管理员核验后可重新上架）。

### 10.3 电话确认怎么操作（三选一）

1. 在"我的房源"找到要维护的房源，点**"电话确认"**。
2. 系统会**自动弹出拨号**，拨打房源登记的房东电话（没登记电话会提示先补充）。
3. 打完电话回到小程序，会弹出三个选项，**按房东告诉你的实际情况选**：

| 选项 | 含义 | 系统动作 |
| --- | --- | --- |
| **未出租** | 房子还在租，房源有效 | 提示"已更新·房态已维护"，核验周期重新计时 |
| **已出租** | 房子已经租出去了 | 提示"已下架该房源"，自动下架进后台资产池 |
| **不租了** | 房东不再出租 | 提示"已下架该房源"，自动下架进后台资产池 |

> 注意：只有选**"未出租"**才算维护成功、房源继续在架；选"已出租"或"不租了"房源会立即下架，之后房东又要租了，可以联系管理员从废房源池重新上架。

> "我的房源"还有**公司模式**（从首页公司房源卡进入），只展示公司当前可租房源，没有"上传""编辑""电话确认"按钮，只能查看和筛选。

## 11. 记录带看（拍水印现场照换额度）

真实带看不仅能证明你在跟进客户，**审核通过后当天还能多拿 1 个普通房源查看额度**。

**入口：** 房源详情页"地址和房东联系方式"卡片下方的**"拍水印照片记录带看"**卡。

### 操作步骤

1. 点"拍水印照片记录带看"。
2. 弹窗说明"请现场拍摄带时间和地点水印的照片。提交后进入后台人工审核，通过后当天普通房源查看额度 +1。"点**"开始拍照"**。
3. **必须现场用相机拍照**（不能从相册选旧图），系统会自动获取定位，并在照片上叠加水印（含时间、房源、房号、位置）。
4. 提交后进入后台审核，成功提示**"带看照片已提交审核"**。

- **提示"未授权定位"**：会用房源信息作为位置参考兜底，仍可提交，但建议开定位更准确。

## 13. 分佣规则与查看

详情页会展示由服务器计算的房东总佣金、带看人、房源维护人和平台服务费占月租比例，**中介不能自己改**。当前报备/签单暂停；“分佣记录”只用于查看存量历史。

### 现行规则

历史恢复规则中，房东总佣金先按“成交月租 × 房源佣金比例”由服务器自动计算，再按默认带看人 70%、维护人 20%、平台 10% 拆分；客户端不能手填最终金额或人员：

| 房源类型 | 上传人到手（现行默认） | 平台留存（现行默认） |
| --- | --- | --- |
| **二房东房源** | **20%** | 10% |
| **业主房源** | **20%** | 10% |
| **公司房源** | **不分佣（0）**，带看中介全佣 | 0 |
| 管理员上传的房源 | 0% | 仍按配置（默认 10%） |

> 比例来自后台配置。若未来恢复，签单时会按当时规则冻结快照；当前页面不提供新增签单。
> 特例：**自己上传、自己带看成交**的房源全免分佣（你实收 100%，不生成分佣记录）。

举例：房东实付佣金 3000 元
- 二房东/业主房源：上传人到手 3000 × 20% = **600 元**，平台留 300 元，带看成交中介净留 2100 元；
- 公司房源：**不分佣**，带看中介全佣。

### 在哪里看分佣

"我的"页 → **"分佣记录"**。每条能看到房源、结算规则、预计到手金额、你的角色（"我是上传人"/"我是成交人"）、状态和时间。

## 14. "我的"页总览

- **用户卡**：头像、姓名、角色、实名标签；右侧有**"切换账号"**，登录后还有**"修改密码"**和**"退出登录"**。

- **内部工作台**：六个入口卡片，每个只显示**名称 + 数值徽标**（如"我的房源 12 套""房源足迹 35 条""房态维护 3/5/7天"）——我的房源、上传房源、房源足迹、分佣记录、房态维护、登录与账号信息。
- **今日工作台**：当天要关注的提醒（敏感信息查看、历史分佣、房态维护），点"全部"可以去足迹页看明细。

## 15. 房源足迹（防跳单）

**入口：** "我的"页 → **"房源足迹"**。

这是防跳单的记录中心：

- 顶部统计：我查看、看我房、电话查看、地址查看。
- 可按标签筛选：**我的房源被查看 / 电话查看**，默认显示“我的房源被查看”。

中介端只显示最近 7 天；管理员后台保留最近 90 天。第 7 天从中介端不可见时不会立即删除后台审计记录；实际打开系统拨号页成功后才会计入“电话查看”。

**要点：** 你查看别人房源的房东电话/地址，会同步给该房源的上传人和管理员；同样，别人查看你上传房源的敏感信息，你也能在这里看到——这样成交归属和分佣就清清楚楚。

## 16. 把房源视频转发给租客

**入口：** 房源详情页（**有视频的房源**才显示）顶部**"转发房间视频给租客"**卡。

- 卡片说明写着"只转发视频和公开摘要，不包含地址、房东电话、楼栋单元房号。"
- 点**"一键转发"**，可以把房源视频分享到微信会话给租客。转发会留痕。

**租客点开后看到什么：** 一个只有视频播放器的页面，**不包含任何地址、电话、楼栋房号信息**。

- 未登录时按钮不可用，会提示先登录内部中介账号。
- 房源没有视频时会提示"这套房源暂无可转发视频。"

## 17. 常见问题速查

| 你遇到的情况 | 原因 / 怎么办 |
| --- | --- |
| **忘记密码怎么办** | 自己改密码需要原密码；原密码想不起来时，**联系管理员在后台"账号管理"里帮你重置一个初始密码**，用初始密码登录后再到"我的 → 修改密码"改成自己的。 |
| **注册后多久开通** | 注册申请提交后进入管理员的待审核列表，**由管理员人工审核**，没有固定时限。着急用就直接联系管理员报姓名+手机号，请他尽快在后台通过；通过后你注册时设的密码即可登录。 |
| 注册时提示**"该手机号已开通"** | 你已经有账号了。按弹窗引导直接登录；若提示"尚未设置登录密码"，找管理员先设初始密码。 |
| 登录提示**"该手机号未开通内部中介账号"** | 还没有账号或申请还没通过。提交注册申请并联系管理员审核开通。 |
| 登录提示**"账号尚未设置登录密码"** | 老账号/后台建的账号没有密码。联系管理员在后台"设置密码"，拿到初始密码再登录。 |
| **账号被停用怎么办** | 停用后登录会提示手机号未开通/无法登录，所有操作都进不去。**联系管理员确认停用原因**；如属误停或恢复合作，由管理员在后台恢复或重新开通账号（历史房源、成交、分佣数据都还在，不会丢）。 |
| 一进操作就弹**"去登录"** | 登录已过期（约一周）。重新用手机号+密码登录即可，记录不会丢。 |
| **为什么看不到房东电话** | 两个原因：① 房东电话是敏感信息，必须在详情页点"查看地址和电话"并二次确认留痕后才显示；不再需要需求单或用途。② 每天有额度：业主房源 3 套/天、普通房源 15 套/天；额度用尽可传带看水印照换普通额度 +1、找管理员协助或次日再看。 |
| 查看房东电话提示**"需要实名认证"** | 按提示完成实名后再查看。 |
| 找房助手**推荐为空** | 放宽预算、区域或户型再试。 |
| 想改需求（如只改预算） | 在找房助手里**再发一句**"预算改成 XXXX，其它不变"。 |
| 上传房源**提示"还差一点"** | 按提示补齐缺的必填项；合作房源必须上传视频（≤60 秒、≤300MB）。 |
| 上传的业主房源**没上架** | 业主房源和小区未匹配的房源要**管理员审核通过**后才上架，请等待或联系管理员。 |
| 我的房源提示**"7天未维护 / 即将失效"** | 去"我的房源"点"电话确认"，打电话确认后选**"未出租"**更新房态。第 7 天不更新会自动下架。 |
| 电话确认时**点错选了"已出租"** | 房源已下架进后台资产池，联系管理员在"废房源池"重新上架。 |
| 房源卡片**封面是灰色占位、没有图** | 封面取自视频第一帧，个别视频暂时取不到帧时显示占位图，**不影响进详情看视频**；持续出现可反馈给管理员。 |
| 想按**公司/业主/二房东**筛选房源 | 房源列表页**顶部分类**或地图页"房源类型"里都可以筛。 |
| 找不到报备/签单入口 | 当前功能已暂停，详情和“我的”页不再提供入口；历史数据保留只读，请按团队线下流程处理。 |
| 分佣多久到 / 怎么算 | 当前只显示历史分佣和详情佣金比例。新签单已暂停；历史恢复规则由服务器按月租、房源佣金比例和冻结拆分计算，客户端不能手填结果。 |
